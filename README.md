**Aula 01 — 10/08/2026**

Nesta aula tivemos uma introdução à disciplina. O professor apresentou o plano de ensino para o semestre e explicou sobre as linguagens de programação que iremos estudar ao longo da matéria.

A aula teve como objetivo despertar o interesse pela construção de programas de computador e mostrar a importância e a utilidade da programação no nosso dia a dia.

O primeiro programa apresentado foi o OctoStudio, que utiliza o Scratch como linguagem de programação. É uma linguagem visual baseada em blocos de código que se encaixam como peças de um quebra-cabeça, facilitando a criação de programas de forma mais intuitiva.

Utilizamos o OctoStudio para desenvolver um programa de apresentação pessoal, que foi apresentado para a turma.
